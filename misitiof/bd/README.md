# Base de datos para el paquete del sitio

`sistem_fares.sql` es la copia para importar en phpMyAdmin al preparar el sitio para hosting. La fuente principal del esquema está en `../basedatos.sql`; vuelve a copiarla aquí después de cambiar el esquema.

El respaldo de clientes antiguos no debe incluirse en el paquete público. Configura las credenciales de producción en el hosting, fuera del código fuente.
